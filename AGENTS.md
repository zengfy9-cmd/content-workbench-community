# Installation and maintenance

- Read README.md and docs/WORKBUDDY.md first. This is a blank, local-first content workbench.
- Never copy credentials, account sessions, databases or content from another installation.
- Keep private data outside the checkout; default Windows path is %LOCALAPPDATA%/ContentWorkbenchCommunity/default.
- Only use the user's explicitly chosen private data directory. Do not search their computer for configuration, browser profiles, character references or model credentials.
- External integrations are optional and require this installation owner's own authorization. Do not call paid models or send drafts during basic installation verification.
- Preserve LICENSE and third-party attribution. Test changes before committing. Do not publish or upload user data.
- Verify save/reload with clearly marked temporary content and clean up only those records. Never reset an existing database to make an installation pass.
