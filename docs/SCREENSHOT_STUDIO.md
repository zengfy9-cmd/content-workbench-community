# 内置截图工作室

在工作台可以添加截图标注、打码、保存编辑项目或导出图片。

## 复用与入口

- 内置 Canvas 编辑器支持标注、背景、自备水印、保存、撤销、导出和回填。渲染器的 MIT 许可证位于 `src/content_workbench/screenshot_assets/LICENSE`。
- 侧栏「截图工作室」可继续项目或上传独立截图。稿件页「截图标注」先保存当前稿件，然后按作者选择的图片创建项目，不能自动把所有 AI 插图当成真实截图。
- 从现有本地项目导入时仅复制编辑状态和图片。原来的 Markdown/Obsidian 路径不成为云端文件写入授权；这类项目仅能编辑和导出。

## 保留编辑器，替换存储边界

编辑器由受保护的 `/api/screenshot-projects/{id}/editor` 提供，用同源 iframe 隔离样式，不依赖本地临时端口。路由继承原账户校验，仅该静态编辑页允许同源嵌入，其余页面仍拒绝嵌入。项目中的图片只接收经校验的内嵌 PNG/JPEG/WebP，不代抓远程资源或执行文件路径。用户资料不会插入 HTML 或脚本。

`screenshot_projects` 保存原图、布局、标注和服务器掌握的原稿绑定，`screenshot_project_history` 保留最近五次保存，`screenshot_exports` 保存导出的 PNG/ZIP。它们都在原有私有数据库中，跟随账号访问和既有数据库快照备份。只有作者点击回填按钮才写原稿；保存和导出不改正文。项目写入以服务器 revision 和项目 token 做并发校验。

## 原稿回填

- 保存、导出和回填分别显示状态。刷新后以实际保存的项目为准；原稿仍存在且图片未再编辑时可显示已回填。自动保存与手动保存共用串行保存队列。
- 回填之前先从服务端读取待替换位置，在确认框里核对目标稿件、图片序号及选择。后端要求明确确认，并检查预览后项目和原稿是否发生变化；冲突时保持原稿并要求重新核对。独立截图项目依然不能回填。

- 对当前正文重新解析真实 Markdown 图片引用，跳过代码段和代码块中的示例，不用旧全文覆盖新全文。
- 仅替换该项目仍存在的已绑定 `/api/images/{id}` 引用。新文字、无关图片、原图与确认成稿保持；被作者移除的图片不会被重插。
- 成图另存原稿附件，写入前保存原稿历史版本。正文和排版签名自然失效，须重新审核才能向平台推送。
- 重复回填相同 PNG 幂等；继续改图后再次回填产生独立附件，旧图仍可恢复。
- 绑定、图片格式或项目版本不匹配时拒绝回填并说明原因。原稿正在生成或改稿时不回填。

## 验证

`tests/test_screenshot_studio.py` 覆盖鉴权、原图保护、保存恢复、并发、导出、备份与精准回填；`tests/test_screenshot_studio_browser.py` 使用隔离内容执行实际 iframe 画布拖框、保存、导出及回填，单独验证无原稿绑定时按钮禁用。没有调用模型、付费接口、外部平台或改写真实历史稿件。

公开参考核对：MDN [iframe](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/iframe)、[同源策略](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Same-origin_policy)。采用同源认证与独立静态编辑器，不把云端页面嵌入临时 loopback HTTP 服务。
