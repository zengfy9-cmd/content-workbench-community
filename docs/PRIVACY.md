# 发布脱敏范围

本版使用代码文件白名单导出到独立目录，重新建立 Git 仓库；未复制原仓库历史。

- 包含：应用源码、测试、依赖锁文件、通用安装与维护说明、许可证。
- 排除：原数据库、正文、素材、图片、个人判断、原使用截图、日志、配置、密钥、浏览器资料、登录状态、原聊天规则、原私有文档及旧 Git 历史。
- 移除：原安装者的产品名、专属角色描述、角色图来源路径、个人工作目录和模型连接器路径。配图使用安装者自备参考图。
- 默认：空库、独立私有目录、文字模型禁用、飞书自动采集及同步关闭，不复制任何账户授权。
- 第三方软件作者署名和公开许可证是项目来源信息，予以保留。测试中的 example.com 等值为模拟数据。

后续提交仍须检查变更；.gitignore 不是自动脱敏工具。不要把私有目录、安装验收图片或账号凭据提交到仓库。
