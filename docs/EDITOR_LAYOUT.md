# 正文排版与提示词

- 选中文字，点击工具栏「居中」或「左对齐」。手动对齐随正文保存，并优先于公众号主题；切换主题和复制排版仍保留。
- 选中一段或连续几段提示词，点击「提示词」。编辑区出现独立提示词块和「复制提示词」按钮；在提示词块中再次点击工具栏「提示词」可恢复正文。
- 提示词块保存纯文本，支持换行、文件路径、Markdown 符号及内部代码围栏。编辑区和文章预览的复制按钮只复制提示词原文。
- 排版导出的公众号正文保留提示词文本，不包含工作台操作按钮。公众号正文中的交互能力不在此功能承诺范围内；需要面向读者的一键领取页面时另行设置。
- 换行不再写入可能显示为斜杠的段末标记；旧版连续空换行标记在显示时兼容处理。已有稿件不批量重写。真实反斜杠、文件路径和代码仍需原样保留。

验收包含真实浏览器中的选择、对齐、提示词复制、保存重开、换主题及复制排版，使用临时测试数据，不调用模型或投递平台。
